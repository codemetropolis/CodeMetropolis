# Check issue no. #163's solution if the provided warning message is in accoradance with the given arguments

## Tags
#pullRequest_163 #component_converter #category_input

_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/163-conversion-without-any-parameters-is-not-handled-correctly

### Purpose
The purpose of this test is to see when running the converter module (from the solution committed to issue no. #163) with only the *-s* switch and it's parameter it gives back a warning message about the missing arguments and leaves out the *-s* switch from the message.

### Pre-requisites
- Java runtime 22
- Command line opened in the folder of mapping-1.5.0.jar

### Steps
1. Run:
   ```cmd
   java -jar mapping-1.5.0.jar -s "CodeMetropolis\examples\sourcemeter graph\codemetropolis-toolchain-rendering.graph"
   ```
   in mapping-1.5.0.jar command line

### Expected Result
The tool writes a message in the console about the missing arguments for the converter module and it does not include the s switch and the graph file path.
