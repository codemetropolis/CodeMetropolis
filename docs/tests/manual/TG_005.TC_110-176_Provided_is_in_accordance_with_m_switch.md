### Purpose
The purpose of this test is to see when running the mapping module (from the solution committed to issue no. #176) with only the *-m* switch and it's parameter it gives back a warning message about the missing arguments and leaves out the *-m* switch from the message.

### Pre-requisites
- Java runtime 22
- Command line opened in the folder of mapping-1.5.0.jar

### Steps
1. Run    in mapping-1.5.0.jar command line:
   ```cmd
   java -jar mapping-1.5.0.jar -m "CodeMetropolis\examples\mapping\sourcemeter_mapping_example_2_0.xmln"
   ```

### Expected Result
The tool writes a message on the console about what kind of parameters can be used with the mapping module.
