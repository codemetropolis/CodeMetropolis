# Check issue no. #225's solution if it provides (sub)processes when running converter in verbose mode

## Tags
#pullRequest_225 #component_converter #category_output

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/225
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/225-extending-the-sourcemeter-converter-with-verbose-mode

### Purpose
The purpose of this test is to check if the provdied messages that appear in the console (when running the solution to issue no. #225) contain **(sub)processe**. The module that needs to be checked for this is the converter and it has to be ran in *verbose* mode.

### Pre-requisites
- Java runtime 22
- Command line opened in the folder of converter-1.5.0.jar
- Test file inserted into the converter-1.5.0.jar's folder. (Has to be a valid file)

### Steps
1. Run 
   ```cmd
   java -jar converter-1.5.0.jar -t sourcemeter -s codemetropolis-toolchain-commons.graph -v
   ```
  in converter-1.5.0.jar command line

### Expected Result
The messages that appear in the console contain the (sub)processes used during the module's runtime.
