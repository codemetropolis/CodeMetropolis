# Check issue no. #163's solution if the provided warning message is in accordance with the given arguments

## Tags

### Purpose
The purpose of this test is to see when running the converter module (from the solution committed to issue no. #163) with only the *-t* switch and it's parameter it gives back a warning message about the missing arguments and leaves out the *-t* switch from the message.

### Pre-requisites
- Java runtime 22
- Command line opened in the folder of mapping-1.5.0.jar

### Steps
1. Run 
   ```cmd
   java -jar converter-1.5.0.jar -t sourcemeter
   ```
   in converter-1.5.0.jar command line

### Expected Result
The tool writes a message in the console about the missing arguments for the mapping module and it does not include the t switch and it's type parameter.
