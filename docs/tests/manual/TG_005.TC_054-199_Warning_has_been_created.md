### Purpose
 The purpose of this test is to see if the solution committed to issue no. #199 creates a warning when rendering is ran with an invalid input file.

### Pre-requisites		
- Java runtime 22
- Command line opened in the folder of rendering-1.5.0.jar
- A *placingToRendering.xml* file exists in the rendering-1.5.0.jar's folder. (Has to be a valid file, which was produced by running placing-1.5.0.jar with the *mappingToPlacing.xml* as input, which was generated by mapping-1.5.0.jar with the *cdfFile* generated by converter-1.5.0.jar with codemetropolis-toolchain-commons.graph as input)

### Steps
1. Open placingToRendering.xml in any kind of text editor
2. Delete its content from line 10 to 20 and save the file
3. Run:
   ```cmd
   java -jar rendering-1.5.0.jar -i placingToRendering.xml -w world
   ``` 
   in rendering-1.5.0.jar command line

### Expected Result
Warning appears in the console that the input file is invalid.
