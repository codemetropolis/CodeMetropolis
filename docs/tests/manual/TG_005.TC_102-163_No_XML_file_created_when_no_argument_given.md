# Check issue no. #163's solution that it does not create an xml file when running converter without arguments

## Tags

### Purpose
The purpose of this test is to check that when running the converter module without any arguments it does not create any xml file as output of the command.

### Pre-requisites
- Java runtime 22
- Command line opened in the folder of mapping-1.5.0.jar

### Steps
1. Run:
   ```cmd
   java -jar converter-1.5.0.jar
   ```
   in converter-1.5.0.jar command line
2. Check the folder of `\CodeMetropolis\sources`

### Expected Result
No xml file was created as a result when running the converter module without any arguments.
