### Purpose
The purpose of this test is to see if the solution committed to issue no. #1163 will not write any error messages in the console when the mapping tool is ran without arguments.

### Pre-requisites
- Java runtime 22
- Command line opened in the folder of converter-1.5.0.jar

### Steps
1. Run:
   ```cmd
   java -jar converter-1.5.0.jar
   ```
   in converter-1.5.0.jar command line

### Expected Result
After running the command, no error is given back in the console.
