
# Test mapping with empty scale parameter

## Tags
#component_mapping #testFile-format_XML  #category_input #category_error_handling

### Pre-requisites

* Java runtime 1.8

* converterToMapping.xml exists in the mapping-1.4.0.jar's folder and is a valid cdfFile (produced by converter-1.4.0.jar with the input codemetropolis-toolchain-commons.graph)

* sourcemeter_mapping_example_2_0.xml mapping description exists in the mapping-1.4.0.jar's folder and is valid

* command line opened in the folder of mapping-1.4.0.jar
	
### Steps
		
1. Run
   ```cmd 
   java -jar mapping-1.4.0.jar -i converterToMapping.xml -m sourcemeter_mapping_example_2_0.xml -s 
   ```
	
### Expected result
		
The tool warns the user that the scale parameter value is missing and exits normally without creating the output file.
