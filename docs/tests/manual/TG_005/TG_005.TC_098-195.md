# [Test] Check issue no. #195's solution that the placing module exits normally when missing layout parameter is used

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/195
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/195-placing-with-empty-layout-parameter-is-not-handled-correctly

**Purpose**: The purpose of this test is to see if the solution committed to issue no. #195 will exit the placing module normally when no layout parameter is given.

**Pre-requisites**:		
- Java runtime 1.8
- Command line opened in the folder of placing-1.4.0.jar
- A *mappingToPlacing.xml* file exists in the placing-1.4.0.jar's folder. (Has to be a valid file, which was produced by running converter-1.4.0.jar with the *converterToMapping.xml* as input)

**Steps**:
1.  Run `java -jar placing-1.4.0.jar -i mappingToPlacing.xml -l` in rendering-1.4.0.jar command line

_Expected result:_
The placing module finished running and exited normally when the layout parameter was missing from the command used for running the module.
