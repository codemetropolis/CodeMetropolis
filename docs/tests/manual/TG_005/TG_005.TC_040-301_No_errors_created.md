### Purpose
 The purpose of this test is to check immaculacy of the code committed to issue no. #301. In other words to check that the modified code won't create errors when ran through command line commands (the errors would appear on the command line and the app would stop).

### Pre-requisites
- Java runtime 1.8
- Apache Maven 3.8.0 or above
- Git bash with latest version
- Open four command lines, one in each of the following files' folders: <u>converter-1.4.0.jar</u> /  <u>mapping-1.4.0.jar</u> /  <u>placing-1.4.0.jar</u> /  <u>rendering-1.4.0.jar</u>
- Valid test .graph file for converter-1.4.0.jar
- Valid test .xml file for mapping-1.4.0.jar

### Steps
1. Run `java -jar converter-1.4.0.jar -t sourcemeter -s "`[CodeMetropolis project folder path](obsidian://open?vault=CodeMetroTests&file=TG_005%2FLegends%2FLegends%20and%20other%20additions)`\examples\mapping\sourcemeter_mapping_example_2_0.xml"`

in converter-1.4.0.jar command line
4. Run `java -jar mapping-1.4.0.jar -i converterToMapping.xml -m "`[CodeMetropolis project folder path](obsidian://open?vault=CodeMetroTests&file=TG_005%2FLegends%2FLegends%20and%20other%20additions)`\examples\mapping\codemetropolis-toolchain-rendering.graph"` in mapping-1.4.0.jar command line
5. Run `java -jar placing-1.4.0.jar -i mappingToPlacing.xml` in placing-1.4.0.jar command line
6. Run `java -jar rendering-1.4.0.jar -i placingToRendering.xml -world world` in rendering-1.4.0.jar command line

Each command line command run gives back a **"Process finished with exit code 0"** message
not a **"Process finished with exit code 1"** message and no errors at all appear on the command line.
