# [Test] Check issue no. #225's solution when using -verbose or -VERBOSE switch reaction.

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/225
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/225-extending-the-sourcemeter-converter-with-verbose-mode

**Purpose**: The purpose of this test is to see if the tool can accept *-verbose* and *-VERBOSE* switches and runs as intended and after gives back detailed information

**Pre-requisites**:		
- Java runtime 1.8
- Command line opened in the folder of converter-1.4.0.jar
- A *codemetropolis-toolchain-commons.graph* file exists in the converter-1.4.0.jar's folder. (Has to be a valid file)

**Steps**:
1. Run `java -jar converter-1.4.0.jar -t sourcemeter -s codemetropolis-toolchain-commons.graph -verbose` or `java -jar converter-1.4.0.jar -t sourcemeter -s codemetropolis-toolchain-commons.graph -VERBOSE` in converter-1.4.0.jar command line

_Expected result:_
The tool gives back warnings or errors and the program will not finnish running, because the -VERBOSE or -verbose switches are not the same as the -v switch.

_Test result:_
`Incorrect command line arguments.`
`Usage: java -jar converter.jar -t <type> -s <source> [-o <outputFile>] [-p <parameters>] [-v]`
