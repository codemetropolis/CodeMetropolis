# Check issue no. #195's solution if it will give back a console warning message when a layout parameter is given

## Tags
#pullRequest_195 #component_placing #category_output 

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/195
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/195-placing-with-empty-layout-parameter-is-not-handled-correctly

### Purpose
The purpose of this test is to see if the solution committed to issue no. #195 gives back an error when the layout switch and parameter are used correctly when running the placing module.

### Pre-requisites
- Java runtime 1.8
- Command line opened in the folder of placing-1.4.0.jar
- A *mappingToPlacing.xml* file exists in the placing-1.4.0.jar's folder. (Has to be a valid file, which was produced by running converter-1.4.0.jar with the *converterToMapping.xml* as input)

### Steps
1. Run 
   ```cmd
   java -jar placing-1.4.0.jar -i mappingToPlacing.xml -l pack
   ```
   in rendering-1.4.0.jar command line

### Expected Result
No error is given back by the palcing module when the layout switch and parameter are used correctly.
