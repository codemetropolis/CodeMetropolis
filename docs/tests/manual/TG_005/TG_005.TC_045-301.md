# [Test] The solution committed to issue no. #301 will not create a monster spawner block if no danger attribute is present in the xml file.

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/301
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/301-put-monsters-and-swords-in-the-high-metric-buildings

**Purpose:** The purpose of this test is to see if a danger attribute is not present for the building in the .xml file of the world, the solution won't create a Minecraft monster spawner block.
(Reference to the mentioned Minecraft spawner object: https://minecraft.fandom.com/wiki/Monster_Spawner)

**Test file:**
- File supplemented by danger attribute for a building: [[placingToRendering.xml]]

**Pre-requisites:**		
- Java runtime 1.8
- Minecraft 1.8 or above
- Test file inserted inserted into `CodeMetropolis\sources\distro\` folder

**Steps:**
1. Navigate to `CodeMetropolis\sources\distro\` folder
2. Open the command line in this folder
3. Run `java -jar rendering-1.4.0.jar -i placingToRendering.xml -world world` in rendering-1.4.0.jar command line
4. [Go over this Minecraft world opening guide](obsidian://open?vault=CodeMetroTests&file=TG_005%2FShared%20steps%2FHow%20to%20open%20created%20Minecraft%20world)
5. Find three of the highest buildings in the opened Minecraft world and go into the bottom of them

_Expected result:_
You should not be able to find a monster spawner block (or multiple blocks) after checking these high buildings.
