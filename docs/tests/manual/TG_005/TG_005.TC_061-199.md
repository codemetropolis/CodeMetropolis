**Purpose**: The purpose of this test is to see that the solution committed to issue no. #199 runs as intended and exits out normally (while not giving back a warning) when the *-i* switch and it's parameter is swapped. - Java runtime 1.8
- Command line opened in the folder of rendering-1.4.0.jar

(Has to be a valid file, which was produced by running placing-1.4.0.jar with the *mappingToPlacing.xml* as input, which was generated by mapping-1.4.0.jar with the *cdfFile* generated by converter-1.4.0.jar with codemetropolis-toolchain-commons.graph as input)

**Steps**:
1. Run `java -jar rendering-1.4.0.jar -w world -i placingToRendering.xml` in rendering-1.4.0.jar command line

_Expected result:_
No warning appears in the console and the tool finishes running as intended
