# Check issue no. #195's solution for -l switch swap with -i switch

## Tags
#pullRequest_195 #component_placing #category_input 

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/195
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/195-placing-with-empty-layout-parameter-is-not-handled-correctly

### Purpose
The purpose of this test is to check if the issue's solution also works as intended when the argument order of the *-i* and *-l* swtiches have been swapped and a warning is returned

### Pre-requisites
- Java runtime 1.8
- Command line opened in the folder of placing-1.4.0.jar
- A *mappingToPlacing.xml* file exists in the placing-1.4.0.jar's folder. (Has to be a valid file, which was produced by running converter-1.4.0.jar with the *converterToMapping.xml* as input)

### Steps
1.  Run 
   ```cmd
   java -jar placing-1.4.0.jar -l -i mappingToPlacing.xml
   ```
   in rendering-1.4.0.jar command line
   
### Expected Result
The tool warns the user that the layout siwtch's parameter is missing and the program finishes running.
