# Check issue no. #203's solution for missing -w or -world switch

## Tags
#pullRequest_203 #component_rendering #category_input

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/203
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/203-rendering-with-empty-world-parameter-is-not-handled-correctly

### Purpose
 The purpose of this test is to see if the issue's solution gives back a warning that the world switch is missing.

### Pre-requisites	
- Java runtime 1.8
- Command line opened in the folder of rendering-1.4.0.jar
- A *placingToRendering.xml* file exists in the rendering-1.4.0.jar's folder. (Has to be a valid file, which was produced by running placing-1.4.0.jar with the *mappingToPlacing.xml* as input, which was generated by mapping-1.4.0.jar with the *cdfFile* generated by converter-1.4.0.jar with codemetropolis-toolchain-commons.graph as input)

### Steps
1. Run
```cmd
   java -jar rendering-1.4.0.jar -i placingToRendering.xml
```
in rendering-1.4.0.jar command line

### Expected Result
The tool gives back a warning as answer to the user that the world (-w or -world) switch is missing.
