# Check issue no. #176's solution if the provided warning message is in accordance with the given arguments

## Tags
#pullRequest_176 #component_mapping #category_input 

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/176
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/176-mapping-without-any-parameters-is-not-handled-correctly

### Purpose
The purpose of this test is to see when running the mapping module (from the solution committed to issue no. #176) with only the *-m* switch and it's parameter it gives back a warning message about the missing arguments and leaves out the *-m* switch from the message.

### Pre-requisites
- Java runtime 1.8
- Command line opened in the folder of mapping-1.4.0.jar

### Steps
1. Run 
   ```cmd
   java -jar mapping-1.4.0.jar -m "CodeMetropolis\examples\mapping\sourcemeter_mapping_example_2_0.xml"
   ```
   in mapping-1.4.0.jar command line

### Expected Result
The tool writes a message in the console about the missing arguments for the mapping module and it does not include the m switch and the xml file path.
