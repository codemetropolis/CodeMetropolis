# [Test] The solution committed to issue no. #301 creates Minecraft chest blocks around monster spawner blocks.

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/301
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/301-put-monsters-and-swords-in-the-high-metric-buildings

**Purpose:** The purpose of this test is to check that solution committed to issue no. #301 will  create chest blocks (https://minecraft.fandom.com/wiki/Chest) around the monster spawner blocks (https://minecraft.fandom.com/wiki/Monster_Spawner) in the Minecraft world's highest buildings' at their lowest floors.

**Test file:**
- File supplemented by danger attribute for a building: [[placingToRendering.xml]]

**Pre-requisites:**		
- Java runtime 1.8
- Minecraft 1.8 or above
- Test file inserted inserted into `CodeMetropolis\sources\distro\` folder

**Steps:**
1. Navigate to `CodeMetropolis\sources\distro\` folder
2. Open the command line in this folder
3. Run `java -jar rendering-1.4.0.jar -i placingToRendering.xml -world world` in rendering-1.4.0.jar command line
4. [Go over this Minecraft world opening guide](obsidian://open?vault=CodeMetroTests&file=TG_005%2FShared%20steps%2FHow%20to%20open%20created%20Minecraft%20world)
5. Go around the world and find the three highest buildings
6. Check the lowest floors of the buildings' and look for monster spawner blocks
7. Break 3x3 blocks behind the doors that are placed around the monster spawner and find the chests

_Expected result:_
There are chests around the monster spawner block at floor level.
