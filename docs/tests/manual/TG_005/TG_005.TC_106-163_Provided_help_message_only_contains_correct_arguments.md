# Check issue no. #163's solution that the provided helping message only contains the correct arguments for the tool

## Tags
#pullRequest_163 #component_converter #category_output

_Related issue:_ https://github.com/codemetropolis/CodeMetropolis/issues/163
_Related branch:_ https://github.com/codemetropolis/CodeMetropolis/tree/163-conversion-without-any-parameters-is-not-handled-correctly

### Purpose
The purpose of this test is to see if the solution committed to issue no. #163 will not give back any extra arguments or have some missing, when a message is given back after running the mapping tool without arguments.

### Pre-requisites
- Java runtime 1.8
- Command line opened in the folder of converter-1.4.0.jar

### Steps
1. Run 
   ```cmd
   java -jar converter-1.4.0.jar
   ```
   in converter-1.4.0.jar command line
2. Compare the arguments that appear in the message given back with: `-t <type> -s <source> [-o <outputFile>] [-p <parameters>]`

### Expected Result
The arguments that appear in the message are similar to the ones provided above.
