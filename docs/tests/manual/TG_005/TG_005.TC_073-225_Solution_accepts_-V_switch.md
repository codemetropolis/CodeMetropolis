### Purpose
The purpose of this test is to see if the tool accepts the capitalized *-V* swtich instead of the normal one.

### Pre-requisites	
- Java runtime 1.8
- Command line opened in the folder of converter-1.4.0.jar
- A *codemetropolis-toolchain-commons.graph* file exists in the converter-1.4.0.jar's folder. (Has to be a valid file)

### Steps
1. Run 
   ```cmd
   java -jar converter-1.4.0.jar -t sourcemeter -s codemetropolis-toolchain-commons.graph -V
   ```
 in converter-1.4.0.jar command line

### Expected Result
The tool gives back warnings or errors and the program will not finnish running, because capitalized -V switch is not the same as the -v switch.
